# Lab 29 — Monitoramento com Zabbix

Monitoramento de um host por agente, com validação da coleta, avaliação de triggers e acompanhamento de uma falha controlada.

**Status:** em desenvolvimento — estrutura inicial e planejamento.

## Objetivo

Verificar o fluxo entre coleta de dados, avaliação de condições, registro de problema e recuperação no Zabbix.

O laboratório deverá demonstrar:

- comunicação entre servidor e agente;
- cadastro e identificação do host monitorado;
- recebimento de valores dos itens;
- interpretação dos intervalos de coleta;
- configuração e avaliação de triggers;
- introdução de uma falha controlada;
- confirmação do problema e da recuperação;
- preservação das evidências;
- cleanup dos recursos exclusivos.
