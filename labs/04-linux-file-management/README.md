# Lab 04 — Navegação e gerenciamento de arquivos no Linux

## Objetivo

Praticar a navegação pelo sistema de arquivos Linux e executar operações básicas de criação, consulta, cópia, movimentação, localização e remoção de arquivos e diretórios.

## Ambiente previsto

- Windows 11;
- WSL 2;
- Ubuntu 24.04 LTS;
- terminal Linux;
- Visual Studio Code;
- Git.

## Competências previstas

- identificar o usuário e o diretório atual;
- reconhecer a estrutura básica do sistema de arquivos Linux;
- navegar entre diretórios;
- criar diretórios e arquivos;
- listar arquivos com diferentes níveis de detalhe;
- copiar e mover arquivos;
- localizar arquivos;
- consultar propriedades e conteúdo;
- remover arquivos e diretórios de forma controlada;
- validar o resultado das operações;
- realizar cleanup do ambiente prático.
